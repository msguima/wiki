# Physics Wiki

Public research wiki of Marcelo S. Guimarães — live at <https://msguima.github.io/wiki/>.

Built with [Quartz 4](https://quartz.jzhao.xyz) from a private Obsidian vault
(the `physics-wiki` repository, which remains the source of truth). `content/`
is generated by `./sync-wiki.sh` and must not be edited here.

## Publishing flow

1. Edit notes in the vault (`~/Projects/physics-wiki`).
2. Run `./sync-wiki.sh` — copies the allowlisted directories into `content/`,
   rewrites wiki links to non-published notes into plain text, and maps
   `last_updated` to the frontmatter key Quartz reads for dates.
3. Review `git diff`; the script prints a report of culled links.
4. Commit and push to `main`; GitHub Actions deploys to Pages.

## Access rules

- The `PUBLISH` list in `sync-wiki.sh` is an **allowlist** — extend the site
  there, never by copying files into `content/` by hand.
- People notes for junior researchers stay private: they are listed in the
  script's `EXCLUDE` array, and links to them become plain text during sync.
- `courses/`, `sources/`, `raw/` and the vault index never leave the vault.
- Before any content-adding push, grep `content/` and the built `public/` for
  emails, junior-researcher names, and fellowship details.

## Upstream

Quartz lives in the `upstream` remote (branch `v4` of `jackyzha0/quartz`);
this repo's `main` carries the site. `quartz.config.ts`, `quartz.layout.ts`,
`sync-wiki.sh`, `scripts/`, and `.github/workflows/deploy.yml` are local
additions — expect small conflicts when merging upstream updates.

One local patch to upstream code: `quartz/plugins/transformers/ofm.ts` fixes
the `disableBrokenWikilinks` check, which compared bare wikilink targets
against folder-qualified slugs and marked every short-form link broken
(Quartz 4.5.2). Drop the patch if upstream fixes it; without it, either turn
`disableBrokenWikilinks` off or every `[[wikilink]]` renders as broken.
