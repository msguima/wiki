# Notation

Consult [[courses/geometric-qcd-course/conventions|conventions]] before translating a source equation.

| Symbol | Meaning | Main location |
|---|---|---|
| $C(\theta),P(\theta)$ | coordinate and momentum contour data | I.1, II.1 |
| $w_C[A],W[C]$ | unaveraged normalized trace and its expectation | I.5 |
| $W_2,W_{2,c}$ | full and connected two-loop correlators | I.5 |
| $\lambda=g^2N_c$ | 't Hooft coupling in the worked color convention | I.1, I.5 |
| $\lambda_{\mathrm{loop}}$ | coefficient in a specified source loop-operator convention | I.5 |
| $D,\mathcal F$ | covariant derivative and its commutator curvature | I.2–I.4 |
| $A_{\mu\nu},\Delta_\mu$ | area insertion and neighboring dot-derivative difference | I.4 |
| $\mathcal L_\nu,L$ | vector loop operator and tangent contraction | I.4 |
| $I^{\mu_1\cdots\mu_n}$ | ordered tensor integral | II.4 |
| $\Omega_{\log}$ | logarithm of an ordered exponential when defined | II.4 |
| $W^{(n)}$ | coefficient tensor in a specified expansion and quotient | II.4–II.6 |
| $S_\chi,\kappa$ | proposed chiral area functional and area coefficient | III.2–III.5 |
| $H,f,Y$ | circle Hilbert transform, holomorphic extension, real harmonic map | III.5 |
| $\Sigma,\eta^{\chi,i}$ | literal source extended area tensor and 't Hooft matrices | III.5 |
| $\lambda_a,\mu_{\dot a}$ | local spinor factors of a complex null matrix | III.6 |
| $\rho,e$ | conformal exponent and separately defined source density | IV.1–IV.2 |
| $\operatorname{Pf}A,\det A,\operatorname{Tr}\log A$ | Majorana Gaussian, determinant, connected-loop generator | IV.3 |
| $k_m$ | normalized radial contact model | IV.6 |
| $\Lambda_{\mathrm{QCD}}$ | RG invariant scale in a specified scheme | IV.7 |
| $\Lambda$ in V.2 | common spinor squared norm, not an RG scale | V.2 |
| $\sigma,\sqrt\sigma$ | string tension and its mass scale | V.7 |
| $x,\bar x,\mathcal E,K,\beta,q$ | dimensionless spectral-model parameters | V.6–V.7 |

Several source symbols are overloaded. Local definitions take precedence over visual resemblance. A coefficient tensor, an iterated integral, and their contraction must not be denoted by the same symbol in a derivation.
