# wiki

Single source of truth for this project. Every AI tool works in THIS directory;
do not create tool-specific copies elsewhere.

## Context
Public physics wiki (Quartz 4) deployed at `msguima.github.io/wiki/` via
GitHub Actions (`.github/workflows/deploy.yml`). Generated from the private
`physics-wiki` Obsidian vault, which remains the source of truth for all
content.

## Conventions
- `content/` is generated by `./sync-wiki.sh` and **must not be edited
  here**. Edit the vault, rerun the script, review the diff, commit, push.
  `content/index.md` is the one hand-written page (the landing page).
- The publishing scope lives in `sync-wiki.sh`: the `PUBLISH` allowlist plus
  the `EXCLUDE` array of private people notes. Junior-researcher entity notes
  (students, postdocs) stay private — decision of 2026-09-18; links to them
  are culled to plain text by `scripts/cull-links.py`, which also maps
  `last_updated:` to `modified:` for Quartz dates.
- Privacy gate before any content-adding push: grep `content/` and the built
  `public/` for emails, junior-researcher names, and fellowship details;
  report anything not already public on the main site before pushing.
- Local `main` carries the site; upstream Quartz is the `upstream` remote
  (its `v4` branch). `quartz.config.ts`, `quartz.layout.ts`, `sync-wiki.sh`,
  `scripts/`, and `deploy.yml` are local additions.
- One patched upstream file: `quartz/plugins/transformers/ofm.ts` — the
  `disableBrokenWikilinks` existence check ignores short-form targets
  (upstream bug in 4.5.2). See README "Upstream" before merging upstream.
- Second patch: `quartz/components/scripts/graph.inline.ts` forces pixi to
  WebGL (upstream hardcodes WebGPU, which renders a blank graph on some
  Chrome/macOS machines).

## Project status in the hub
At the end of every session that changes this project, review `ESTADO.md` before the
last commit: fase, versão, próximo passo and produtos. Update `revisado_em` even if
nothing else changes. Phases for this area: ideia, construção, teste, em uso, estável.
Under Produtos list only PDFs and HTML pages from this repository that may go to the
hub site, or external links. Never list referee reports, student data or assessment
documents.
